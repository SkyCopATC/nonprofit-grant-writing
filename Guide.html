1. About This Tool

Grant writing is a high-stakes, high-friction workflow for small nonprofits. Every funder asks for similar information in slightly different shapes — and reusing your boilerplate without it sounding boilerplate is the central craft. This tool gives you one place to manage every active proposal, with shared templates underneath.

Multi-proposal model

Most teams have 3-8 proposals in flight at once. The All Proposals view is your queue; click any to make it the "active proposal" and start editing.

2. Getting Started

Demo: demo@example.org / demo — populated with two example proposals (one foundation, one government RFP) plus a starter funder library and template set.

First 30 minutes

  1. Build out your Funder Library with 5-10 funders you're tracking — name, contact, focus area, typical award size, deadlines.
  2. Customize your Templates — mission, history, programs, evaluation language. These get pulled into every proposal.
  3. Create your first proposal in All Proposals — pick a funder, set a deadline.

3. All Proposals & Active Proposal

The All Proposals page lists every proposal with status (drafting, internal review, submitted, awarded, declined), funder, ask amount, and deadline. Sortable and filterable.

Active proposal

Click any proposal to make it "active." A top-bar dropdown shows which proposal you're editing. All section pages (Cover Letter, Need, Approach, Budget, etc.) operate on the active proposal.

4. Proposal Sections

Every proposal is broken into standard sections, each on its own page:

  • Cover Letter
  • Executive Summary
  • Statement of Need
  • Project Description
  • Goals & Outcomes
  • Methodology / Approach
  • Evaluation Plan
  • Organizational Capacity
  • Budget & Budget Narrative
  • Sustainability
  • Attachments Checklist

Each section pulls from your template library by default — you customize for the specific funder.

5. Templates & Funder Libraries

Templates Library

Org-level reusable content — mission statement, history, board list, financial highlights, evaluation framework. Updated once; flows into every proposal.

Funder Library

Every funder you're tracking, whether actively solicited or in research. Captures contact info, focus areas, typical grant size, deadlines, prior history, key relationships.

Administrator Access

The sign-in screen has an Administrator Access link below the Sign In button. Use it to sign in as Administrator with just a password — no email needed. This is a per-browser admin role; the password is stored only on the current computer.

  • First time: Click Administrator Access. You'll see a "First-time setup" prompt with two password fields — enter a password (6+ characters) and confirm it. Click Create Admin Password.
  • Subsequent times: Click Administrator Access, enter that same password, and click Enter Admin Panel.
  • Once signed in as Administrator, you'll land on the dashboard with full admin privileges, including the Admin page in the sidebar (visibility into all teams, users, and activity stored in this browser).
  • Click ← Back to regular sign-in at the bottom of the admin panel to return to the normal email/password form.

Note: the admin password is unique to each browser. If you set it up at home and then visit the app on a work computer, you'll see the first-time-setup prompt again. To grant admin access on a new machine, register a regular user account or set up a fresh admin password there.
